BukowskiOS

A desktop that runs in a browser tab and nowhere else.

Live demo — no login required, just open it.

About

BukowskiOS is a browser-based desktop simulator built with plain HTML, CSS, and JavaScript — no frameworks, no build step. It has draggable, resizable windows, a taskbar, a start menu, and a handful of small apps.

Features
Multiple windows you can drag, resize, minimize, maximize, and close
A taskbar that tracks every open window, plus a start menu to launch apps
about.txt — what this thing is
terminal — a small fake terminal with a few commands (try help)
notepad.txt — autosaves what you type to your browser, so it's still there next time you open it
devlog.txt — my build log, in-app (see Devlog below)
settings — swap the wallpaper; it remembers your choice

Running it locally

No install, no server required:

Clone or download this repo
Open index.html directly in your browser

For live-reload while editing in VS Code: install the Live Server extension, right-click index.html, and choose Open with Live Server.
